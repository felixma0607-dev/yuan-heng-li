# 元亨利

免費繁中易數小工具：通勝／日卦、梅花起卦、金錢六爻、六十四卦辭。

僅供文化／娛樂參考，唔構成專業諮詢。

## 本地

```bash
npm install
npm test
npm run dev
```

開發站預設 `http://127.0.0.1:47281`。

```bash
npm run build
```

靜態檔在 `dist/`。`netlify.toml` 已寫 publish 目錄同 SPA 回退。

## 四頁

- 通勝／日卦：該日香港時間 12:00 做一次時間起卦，**只示本卦**。
- 梅花：時間（預設）或兩數。本卦、互卦、變卦都計。同一問題二十四小時內不重複起卦。
- 金錢六爻：六爻由下而上，手動或虛擬擲滿先至可以起卦。多動則各動爻都變，並標「多動」。
- 六十四卦：搜尋同格子。卦辭、大象、爻辭、變爻全文、短整理。

## 算法同來源

標籤用：通行本、站方整理、標準方法、〔推論〕。

### 時間起卦（標準方法）

地支數：子 1 … 亥 12。

- 上卦＝（年支數＋農曆月＋農曆日）÷8 的餘數；餘 0＝8 坤
- 下卦＝（上述和＋時支數）÷8 的餘數；餘 0＝8 坤
- 動爻＝總和÷6 的餘數；餘 0＝上爻

先天數：1 乾、2 兌、3 離、4 震、5 巽、6 坎、7 艮、8 坤。

年支取農曆年（正月初一換歲），用 `lunar-javascript` 的 `getYearInGanZhi`，不用立春八字年。

閏月用該月序數（閏六月＝6），不另加一。這一點標〔推論〕。

日卦用當日 12:00（午時），只把本卦放到頁面。動爻可在算式裡核對，不展示互卦、變卦。

### 數字起卦（標準方法，預設）

- 數甲 100–500。÷64 的餘數＝卦序；餘 0＝64 未濟
- 數乙 50–100。÷6 的餘數＝動爻；餘 0＝上爻

「兩數各÷8」開關預設關閉，打開只作對照：數甲÷8＝上卦，數乙÷8＝下卦，和÷6＝動爻。

### 互卦、變卦

互下＝本卦二、三、四爻；互上＝三、四、五爻。變卦＝動爻陰陽對調。金錢卦若多於一個動爻，全部對調，標「多動」。

### 體用、月令（標準方法）

下卦＝體＝自己。上卦＝用＝事／對方。五行：乾兌金、震巽木、坎水、離火、艮坤土。

生剋只報關係名：比和、用生體、體生用、體剋用、用剋體。

月令用月建地支（節氣月），對照常規旺相休囚死表：

- 寅卯：木旺、火相、水休、金囚、土死
- 巳午：火旺、土相、木休、水囚、金死
- 申酉：金旺、水相、土休、火囚、木死
- 亥子：水旺、木相、金休、土囚、火死
- 辰戌丑未：土旺、金相、火休、木囚、水死

數字起卦的月令用起卦當下的香港日期。

### 金錢卦字背（本站寫死）

背計 3，字計 2。

| 結果 | 點數 | 爻 | 動靜 |
| --- | --- | --- | --- |
| 三背 | 9 | 老陽 ● | 動 |
| 兩背一字 | 8 | 少陰 | 靜 |
| 一背兩字 | 7 | 少陽 | 靜 |
| 三字 | 6 | 老陰 ○ | 動 |

頁面有同一張表。`npm test` 鎖定呢個對應。

### 曆法

[lunar-javascript](https://github.com/6tail/lunar-javascript)（6tail，MIT）。宜、忌、沖煞、吉神、凶神、空亡、建除、節氣、干支都來自呢個庫，再以 OpenCC 轉成繁體。換算失敗就停止起卦，不會改用別的數硬起。

宜忌可能同坊間通勝有出入。建除同日卦分開。擇日另有一句：黃曆宜忌不代替法律、婚嫁、動土等正式決策。

### 卦文

- 卦辭、爻辭、大象：通行本《周易》。經文屬公有領域。結構化文字取自 [bollwarm/ZHOUYI](https://github.com/bollwarm/ZHOUYI)（Perl 雙授權 GPL 或 Artistic）。大象只取象傳第一句。
- 已改兩處明顯錯字：乾卦九二「見龍再田」改為「見龍在田」；豐卦「丰」改為「豐」。
- 關鍵詞、吉凶、口訣、卦象、變爻全文：站方整理。動爻爻辭用通行本全文。
- 冇收卦義說明長文，冇收問事長文。
